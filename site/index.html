Codex Advisor

Automatic read-only advice for material Codex decisions, with smart defaults and bounded escalation. It advises; your main agent decides.

Install from OpenAI View source

What it does

  1. Finds the decision.Ordinary architecture and interfaces, or evidence-unresolved system boundaries, recovery, trust, and competing diagnoses.
  2. Challenges it read-only.The advisor gets a bounded packet in a read-only sandbox and is instructed to use zero tools.
  3. Returns the call.Your main agent accepts, changes, or rejects the recommendation.

The consultation child runs read-only with post-execution runtime validation: the launcher inspects the recorded runtime after execution and rejects the result on any observed tool call. Direct invocation of installed advisor profiles is unsupported.

Astra starts low

Smart defaults use one active Astra model with bounded escalation. Standard and Specialist are supported entrypoint names. Both start low; they do not select different models.

[advisor]
model = "gpt-6-astra"
effort_ladder = ["low", "medium", "high", "xhigh"]

The supported roles advisor-terra, advisor-sol and advisor-astra all start Astra/low for the next consultation. Only an accepted response requesting the adjacent level and primary authorization permit escalation: low → medium → high → extra_high (runtime xhigh). Sufficient advice stops; extra_high is terminal. Each level has one attempt, with no corrective retry.

Astra is subject to account and runtime availability; the launcher does not silently fall back. Plugin updates may replace edits to the bundled file. Old two-tier configuration needs migration; catalog entries are diagnostic evidence.

Consult only when cheap local evidence leaves unresolved uncertainty with material impact, during an approved-plan checkpoint or an explicit standalone request. Routine, settled-plan, completion and no-delegation work skips consultation.

Long consultations drain the nonterminal shell handoff and require exactly one schema-v3 result envelope after terminal exit. This candidate retains the 1.4.4 result-delivery repair without adding fallback.

This repository candidate has no durable checkpoint/replay/resume enforcement. Live runtime and installed-plugin activation remain unverified; it is not deployed or released.
